# ⚛️ React Study Notes

React হলো Meta (Facebook) দ্বারা উদ্ভাবিত একটি ডিক্লেয়ারেটিভ, কম্পোনেন্ট-বেসড ওপেন সোর্স জাভাস্ক্রিপ্ট ফ্রন্টএন্ড লাইব্রেরি। এটি সিঙ্গেল পেজ অ্যাপ্লিকেশন (SPA) এবং ডায়নামিক ইউজার ইন্টারফেস তৈরিতে ব্যবহৃত হয়।
