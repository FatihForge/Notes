## ১. JavaScript কী? (What is it?)

গত এক দশকেরও বেশি সময় ধরে টেক ইন্ডাস্ট্রিতে **Web Development**-এর জন্য সবচেয়ে প্রভাবশালী এবং জনপ্রিয় প্রোগ্রামিং ল্যাঙ্গুয়েজ হিসেবে নিজের স্থান ধরে রেখেছে **JavaScript (JS)**।

সহজ কথায়, **JavaScript হলো এমন একটি ভাষা যার মাধ্যমে আমরা কম্পিউটার বা ব্রাউজারকে নির্দিষ্ট নির্দেশনা (Instructions) দিই**। মানুষ যেমন নিজেদের মধ্যে ভাব বিনিময়ের জন্য বাংলা, ইংরেজি কিংবা হিন্দি ব্যবহার করে, ঠিক তেমনি কম্পিউটারের সাথে কথা বলার বা তাকে কোনো কাজ করানোর মাধ্যমই হলো এই প্রোগ্রামিং ল্যাঙ্গুয়েজ।

এটি কেবল তাত্ত্বিক কোনো বিষয় নয়—বরং বাস্তব জগতের আধুনিক ওয়েবসাইট, ইন্টারঅ্যাক্টিভ ওয়েব অ্যাপ্লিকেশন, ব্রাউজার গেম এবং ফুল-স্ট্যাক সফটওয়্যার তৈরির অন্যতম প্রধান হাতিয়ার।

### 💡 Core Takeaway

HTML ওয়েবসাইটের **কঙ্কাল বা স্ট্রাকচার** তৈরি করে, CSS দেয় **ডিজাইন ও সৌন্দর্য**, আর JavaScript যুক্ত করে **প্রাণ ও বুদ্ধিমত্তা (Logic & Interactivity)**।

## ২. এটি কেন গুরুত্বপূর্ণ? (Why is it important?)

আধুনিক সফটওয়্যার ইঞ্জিনিয়ারিংয়ে JavaScript অপরিহার্য হওয়ার মূল কারণগুলো নিচে লক্ষ্য করুন:

⚡

### ইন্টারঅ্যাক্টিভ ওয়েবসাইট

JS ছাড়া ওয়েবসাইটে লজিক যোগ করা বা ব্যবহারকারীর অ্যাকশনের (ক্লিক, টাইপ, স্ক্রল) সাথে যোগাযোগ তৈরি করা অসম্ভব।

🔄

### Input-Output Flow

ইউজারের ইনপুট প্রসেস করে কাঙ্ক্ষিত আউটপুট প্রদান করে—সাধারণ ক্যালকুলেশন থেকে শুরু করে রিয়েল-টাইম চ্যাট সিস্টেম পর্যন্ত।

🌐

### সার্বজনীন ব্যবহার

ব্রাউজারের ফ্রন্ট-এন্ডের পাশাপাশি Node.js-এর সাহায্যে সার্ভার ও ব্যাক-এন্ড উভয় ক্ষেত্রে একই ভাষা ব্যবহার করা যায়।

## ৩. ভেরিয়েবল: ডেটা রাখার কন্টেইনার (Variables)

**Variable হলো ডেটা বা তথ্য সাময়িকভাবে জমা রাখার পাত্র (Container)।**

একটি বাস্তব রূপক (Analogy) দিয়ে চিন্তা করুন: ধরুন একটি এলাকা বা জমির প্লট।

### 🏡 মেমোরি ও ভেরিয়েবলের এনালজি

* Memory Location: কম্পিউটারের র‍্যামের (RAM) সেই নির্দিষ্ট প্লট যেখানে তথ্য সংরক্ষিত থাকে।

* Variable Name: সেই প্লটের নাম বা বাড়ির ঠিকানা, যা দেখে আমরা প্রোগ্রামিংয়ে ওই জায়গাটিকে সহজে চিহ্নিত করি।

* Value: ওই বাড়ির ভেতরে থাকা আসল বাসিন্দা বা সংরক্ষিত তথ্য (Data)।

মেমোরিতে সংরক্ষিত তথ্যের মান প্রয়োজন অনুযায়ী পরিবর্তন (**Vary**) হতে পারে বলেই এর নাম হয়েছে *Variable*।

              variable-basics.js

                Copy

```javascript
// 'age' হলো ভেরিয়েবলের নাম, আর 24 হলো মান
let age = 24;

// 'PI' একটি অপরিবর্তনযোগ্য ধ্রুবক (constant)
const PI = 3.1416;

console.log(age); // আউটপুট: 24
console.log(PI);  // আউটপুট: 3.1416
```

## ৪. ভেরিয়েবল নামকরণের নিয়ম (Rules for Variable Names)

JavaScript আর্কিটেক্ট হিসেবে ভেরিয়েবলের নাম দেওয়ার সময় নিচের ৪টি মৌলিক নিয়ম এবং নেমিং কনভেনশন মেনে চলতে হয়:

              01

### Case Sensitivity (কেস সেন্সিটিভিটি)

জাভাস্ক্রিপ্টে ছোট ও বড় হাতের অক্ষর আলাদা। যেমন `fullName` এবং `fullname` দুটি সম্পূর্ণ আলাদা ভেরিয়েবল।

              02

### অনুমোদিত ক্যারেক্টার (Allowed Characters)

নামের মধ্যে কেবল বর্ণ (Letters a-z, A-Z), সংখ্যা (Digits 0-9), আন্ডারস্কোর (`_`) এবং ডলার সাইন (`$`) ব্যবহার করা যাবে। স্পেস বা স্পেশাল চিহ্ন допустиম নয়।

              03

### শুরু করার নিয়ম (Starting Character)

ভেরিয়েবলের নাম কখনো **সংখ্যা দিয়ে শুরু হতে পারবে না**। এটি অবশ্যই কোনো বর্ণ, `_` বা `$` দিয়ে শুরু হতে হবে (যেমন: `user1` বৈধ, কিন্তু `1user` অবৈধ)।

              04

### Reserved Keywords (সংরক্ষিত শব্দ)

JavaScript-এর নিজস্ব কীওয়ার্ড যেমন `let`, `const`, `var`, `function`, `if`, `return` ইত্যাদিকে ভেরিয়েবল হিসেবে ব্যবহার করা যায় না। (`console` কীওয়ার্ড নয়, একটি built-in অবজেক্ট, তবুও এটিকে ভেরিয়েবল হিসেবে পরিহার করা উচিত)।

### 🏷️ Naming Conventions (ইন্ডাস্ট্রি স্ট্যান্ডার্ড)

                camelCase (স্ট্যান্ডার্ড)
                `myFullName`
                JS-এ সর্বাধিক ব্যবহৃত

                PascalCase
                `MyFullName`
                Class তৈরিতে ব্যবহৃত

                snake_case
                `my_full_name`
                Python বা Database-এ বেশি

## ৬. ভেরিয়েবল ডিক্লেয়ারেশনের তুলনা (let vs. const vs. var)

| বৈশিষ্ট্য | var | let | const |
| --- | --- | --- | --- |
| পুনরায় ডিক্লেয়ার (Re-declaration) | সম্ভব (কোডে বিভ্রান্তি ও বাগ তৈরি করে) | সম্ভব নয় | সম্ভব নয় |
| মান আপডেট (Re-assignment) | সম্ভব | সম্ভব | সম্ভব নয় (Immutable reference) |
| স্কোপ (Scope) | গ্লোবাল বা ফাংশন স্কোপ | ব্লক স্কোপ (Block Scoped) | ব্লক স্কোপ (Block Scoped) |
| বর্তমান প্রাসঙ্গিকতা | লেগ্যাসি / পরিহার্য | আধুনিক ও নিরাপদ (যখন মান বদলাবে) | সর্বোত্তম ডিফল্ট চয়েস (Recommended) |

            **Senior Dev Rule of Thumb:** সবসময় প্রথমে `const` ব্যবহার করুন। শুধুমাত্র যখন নিশ্চিত যে ভবিষ্যতে এই ভেরিয়েবলের মান পুনরায় অ্যাসাইন করতে হবে, কেবল তখনই `let` ব্যবহার করুন। `var` কখনোই ব্যবহার করবেন না।

## ৭. ডেটা টাইপ (Data Types)

JavaScript একটি **Dynamically Typed Language**। এর অর্থ হলো কোড লেখার সময় ভেরিয়েবলের টাইপ আগে থেকে বলে দিতে হয় না—কোড রান করার সময় জাভাস্ক্রিপ্ট নিজে থেকেই মানের ওপর ভিত্তি করে ডেটা টাইপ নির্ধারণ করে নেয়।

              Data Architecture

### JavaScript ডেটা টাইপের বিভাজন

#### Primitive Types (৭টি মৌলিক টাইপ)

মেমোরিতে সরাসরি মান হিসেবে সংরক্ষিত থাকে এবং অপরিবর্তনীয় (immutable)।

                  Number
                  String
                  Boolean
                  Undefined
                  Null
                  BigInt
                  Symbol

#### Non-Primitive Types (রেফারেন্স টাইপ)

মেমোরিতে রেফারেন্স হিসেবে থাকে, জটিল ও সম্পর্কিত ডেটার কালেকশন।

                  Object
                  Array
                  Function

### Primitive Types-এর পরিচিতি:

              **1. Number:** পূর্ণসংখ্যা ও দশমিকসহ সব ধরনের সংখ্যা (যেমন: `24`, `99.99`, `-5`)।

              **2. String:** টেক্সট বা অক্ষরসমষ্টি, যা ডাবল বা সিঙ্গেল কোটেশনের ভেতরে থাকে (যেমন: `"Tony Stark"` বা `'Web Dev'`)।

              **3. Boolean:** সত্য বা মিথ্যা—কেবল দুটি মান ধারণ করে: `true` অথবা `false`।

              **4. Undefined:** যখন কোনো ভেরিয়েবল ডিক্লেয়ার করা হয় কিন্তু তাতে কোনো মান অ্যাসাইন করা হয় না।

              **5. Null:** একটি বিশেষ মান যা "মানের অনুপস্থিতি" (Absence of value বা empty object) বোঝায়।

                ⚠️ ঐতিহাসিক Quirk: console.log(typeof null); লিখলে আউটপুট আসে "object"। এটি জাভাস্ক্রিপ্টের প্রথম সংস্করণের একটি পরিচিত বাগ যা পশ্চাৎমুখী সামঞ্জস্যের (backward compatibility) জন্য অপরিবর্তিত রাখা হয়েছে।

              **6. BigInt:** স্ট্যান্ডার্ড Number রেঞ্জের চেয়ে অনেক বড় পূর্ণসংখ্যা সংরক্ষণ করার জন্য ব্যবহৃত হয় (যেমন: `12345678901234567890n`)।

              **7. Symbol:** সম্পূর্ণ অনন্য (unique) ও অপরিবর্তনীয় আইডেন্টিফায়ার তৈরির জন্য ব্যবহৃত হয়।

## ৮. অবজেক্ট (Objects in JavaScript)

**Object হলো একটি Non-Primitive ডেটা টাইপ** যা অনেকগুলো সম্পর্কিত তথ্যের "Key-Value pairs"-এর সমষ্টি। বাস্তব জগতের যেকোনো বস্তুর মতো এর নিজস্ব বৈশিষ্ট্য (Properties) থাকে।

              object-structure.js

                Copy

```javascript
const student = {
  fullName: "Rahul Roy",
  age: 20,
  cgpa: 3.85,
  isEnrolled: true
};

// 1. Dot Notation দিয়ে অ্যাক্সেস:
console.log(student.fullName); // "Rahul Roy"

// 2. Bracket Notation দিয়ে অ্যাক্সেস:
console.log(student["age"]);    // 20

// মান আপডেট করা:
student.age = student.age + 1;
console.log(student.age);       // 21
```

## ৯. সাধারণ ভুলসমূহ (Common Mistakes)

১. সংখ্যা দিয়ে ভেরিয়েবলের নাম শুরু করা

                  ❌ let 1stName = "JS"; // SyntaxError

                  ✅ let firstName1 = "JS";

ভেরিয়েবলের নাম অবশ্যই অক্ষর, আন্ডারস্কোর বা ডলার সাইন দিয়ে শুরু করতে হবে।

২. const-এ শুরুর মান না দেওয়া (Uninitialized Const)

                  ❌ const PI; // SyntaxError

                  ✅ const PI = 3.1416;

const দিয়ে তৈরি ভেরিয়েবলে ডিক্লেয়ারেশনের সময়ই মান দেওয়া বাধ্যতামূলক।

৩. একই ব্লকে let পুনরায় ডিক্লেয়ার করা

                  ❌ let x = 5; let x = 10;

                  ✅ let x = 5; x = 10;

মান পরিবর্তনের সময় পুনরায় let লেখার প্রয়োজন নেই, সরাসরি অ্যাসাইন করুন।

৪. const ভেরিয়েবলের আদি মান পরিবর্তন করার চেষ্টা

                  ❌ const total = 50; total = 60; // TypeError

                  ✅ let total = 50; total = 60;

যে ভেরিয়েবলের মান ভবিষ্যতে পরিবর্তন হবে, তার ক্ষেত্রে let ব্যবহার করুন।

## ১০. কুইক রিভিশন (Quick Revision Checklist)

* ✓
                JavaScript: ব্রাউজার ও মেশিনে নির্দেশনা পাঠানোর জন্য ব্যবহৃত ডায়নামিক স্ক্রিপ্টিং ভাষা।

* ✓
                console.log(): কনসোলে যেকোনো তথ্য ও আউটপুট প্রিন্ট করার ইউনিভার্সাল মেথড।

* ✓
                Variable: মেমোরি লোকেশনের একটি মানব-বোধগম্য নাম যা ডেটা জমা রাখে।

* ✓
                Modern Scope: আধুনিক কোডিংয়ে var বর্জন করুন, ব্লক স্কোপের সুরক্ষার জন্য let ও const ব্যবহার করুন।

* ✓
                ৭টি Primitive ডেটা টাইপ: Number, String, Boolean, Undefined, Null, BigInt, Symbol। মনে রাখবেন typeof null === "object"।

* ✓
                Object: সম্পর্কিত তথ্যের Key-Value জোড়া, যা ডট (obj.key) বা ব্র্যাকেট (obj["key"]) দিয়ে পড়া যায়।
