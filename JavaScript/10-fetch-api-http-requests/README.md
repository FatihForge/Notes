## ১. Fetch API কী? (What is it?)

**Fetch API** হলো আধুনিক জাভাস্ক্রিপ্টের একটি অত্যন্ত শক্তিশালী বিল্ট-ইন ইন্টারফেস, যা ক্লায়েন্ট-সাইড অ্যাপ্লিকেশন (যেমন আপনার ব্রাউজার) এবং এক্সটার্নাল সার্ভারের মধ্যে তথ্য আদান-প্রদানের প্রধান সেতু হিসেবে কাজ করে।

এটি মূলত নেটওয়ার্কের মাধ্যমে রিসোর্স বা ডেটা 'ফেচ' (সংগ্রহ) করতে ব্যবহৃত হয়। আধুনিক ওয়েব ডেভেলপমেন্টে সার্ভার থেকে ডেটা আনতে বা ব্যবহারকারীর ডেটা সার্ভারে পাঠাতে এটি একটি অপরিহার্য টুল।

### 🍽️ মানসিক মডেল: রেস্তোরাঁ ও ওয়েটারের অ্যানালজি

**Customer (Browser / Client):** আপনি টেবিলে বসে খাবার অর্ডার করছেন।

**API (Waiter):** ওয়েটার হলো API। সে আপনার কাছ থেকে অর্ডার (Request) নেয় এবং কিচেনে পৌঁছে দেয়।

**Server (Kitchen):** কিচেন হলো সার্ভার যেখানে খাবার প্রস্তুত হয়। কিচেনের ভেতরে শেফ কীভাবে কাজ করছে তা জানার কোনো প্রয়োজন আপনার নেই।

**Data / Response (Food):** ওয়েটার রান্নাঘর থেকে যে তৈরি খাবারটি আপনার সামনে নিয়ে আসে, সেটিই হলো রেসপন্স বা ডেটা।

## ২. কেন এটি গুরুত্বপূর্ণ? (Why is it important?)

Fetch API ব্যবহারের ফলে ওয়েবসাইটের ইউজার এক্সপেরিয়েন্স (UX) বহুগুণ বৃদ্ধি পায়। এটি ব্যবহার করে আমরা সম্পূর্ণ পেজ রিলোড করা ছাড়াই **'রান-টাইমে' (Runtime)** শুধুমাত্র প্রয়োজনীয় নির্দিষ্ট অংশের ডেটা লাইভ আপডেট করতে পারি।

* Request-Response Cycle: ক্লায়েন্ট সার্ভারে রিকোয়েস্ট পাঠায়, আর সার্ভার কাঙ্ক্ষিত ফলাফল পাঠায়।

* ব্রাউজার ইনসাইট: আপনি যখনই ব্রাউজারের অ্যাড্রেস বারে কোনো ওয়েবসাইটের URL লিখে এন্টার চাপেন, ব্রাউজার ডিফল্টভাবে সার্ভারে একটি GET রিকোয়েস্ট পাঠায়।

* ব্যবহারিক প্রয়োগ: লাইভ আবহাওয়ার পূর্বাভাস, মুদ্রা বিনিময় হার (Exchange Rates), বা ই-কমার্সে প্রোডাক্ট লিস্ট ডায়নামিকভাবে প্রদর্শন করা।

## ৩. The 2-Step Fetch Process (২-ধাপের প্রসেস)

অনেকেই মনে করেন fetch কল করলেই সরাসরি ডেটা অবজেক্ট পাওয়া যায়। কিন্তু আসলে এটি **২টি স্বতন্ত্র প্রমিজের ধাপে** সম্পন্ন হয়:

                Step 1: HTTP Response Stream

`await fetch(URL)` কল করলে প্রথম প্রমিজটি সার্ভারের Response Header ও Data Stream অবজেক্ট রিটার্ন করে (যা সরাসরি পড়া যায় না)।

                Step 2: JSON Parsing

`await response.json()` মেথড বডি স্ট্রিমটিকে পার্স করে এবং **দ্বিতীয় একটি প্রমিজ** রিটার্ন করে, যা জাভাস্ক্রিপ্ট অবজেক্টে পরিণত হয়।

              fetch-example.js
              Copy

```javascript
const API_URL = "https://catfact.ninja/fact";

const getCatFact = async () => {
  try {
    console.log("Requesting data from server...");

    // ধাপ ১: ১ম প্রমিজ — Response অবজেক্ট পাওয়া
    let response = await fetch(API_URL);

    // ধাপ ২: ২য় প্রমিজ — Data Stream পার্স করে JSON পাওয়া
    let data = await response.json();

    console.log("Cat Fact:", data.fact);
  } catch (error) {
    console.error("Network error:", error);
  }
};

getCatFact();
```

## ৪. HTTP Verbs এবং Status Codes

### প্রধান ৪টি HTTP Verbs (Methods):

              GET
              সার্ভার থেকে ডেটা সংগ্রহ করা (ডিফল্ট)

              POST
              সার্ভারে নতুন ডেটা বা রিসোর্স পাঠানো

              PUT / PATCH
              সার্ভারে বিদ্যমান ডেটা আপডেট বা সংশোধন

              DELETE
              সার্ভার থেকে নির্দিষ্ট ডেটা স্থায়ীভাবে মুছে ফেলা

### গুরুত্বপূর্ণ HTTP Status Codes:

| Status Code | স্ট্যাটাস অর্থ | বাস্তব ব্যাখ্যা |
| --- | --- | --- |
| 200 OK | সফল (Success) | রিকোয়েস্ট সফলভাবে সম্পন্ন হয়েছে এবং কাঙ্ক্ষিত ডেটা পাঠানো হয়েছে। |
| 400 Bad Request | ক্লায়েন্ট এরর | ক্লায়েন্ট থেকে পাঠানো রিকোয়েস্টের ফরম্যাটে ভুল রয়েছে। |
| 404 Not Found | খুঁজে পাওয়া যায়নি | কাঙ্ক্ষিত URL বা এন্ডপয়েন্ট সার্ভারে বিদ্যমান নেই। |
| 500 Server Error | সার্ভার ক্র্যাশ / ত্রুটি | সার্ভারের ইন্টারনাল লজিকে কোনো সমস্যা বা ক্র্যাশ ঘটেছে। |

| ডেটা ফরম্যাট | প্রধানত ভারী XML ব্যবহার করা হতো। | প্রধানত লাইটওয়েট এবং জনপ্রিয় JSON ব্যবহৃত হয়। |

| ইন্টিগ্রেশন | প্রমিজ ও আধুনিক সিনট্যাক্স সাপোর্ট ছিল না। | নেটিভভাবে Promises ও Async/Await-এর সাথে চমৎকারভাবে ইন্টিগ্রেটেড। |

## ৬. সাধারণ ভুলসমূহ (Common Mistakes)

১. response.json() মেথডে await না দেওয়া

যেহেতু `.json()` মেথডটিও একটি প্রমিজ রিটার্ন করে, তাই এর আগেও অবশ্যই `await` দিতে হবে। অন্যথায় ভেরিয়েবলে আসল ডেটার বদলে একটি Pending Promise জমা হয়ে থাকবে।

                  let data = response.json(); // ❌ Pending Promise

                  let data = await response.json(); // ✅ Actual JS Object

২. ভাবা যে 404 বা 500 এররে fetch() সরাসরি reject করে

Fetch API শুধুমাত্র নেটওয়ার্ক সম্পূর্ণ বিচ্ছিন্ন হলে বা ইন্টারনেট কানেকশন ড্রপ করলেই প্রমিজ রিজেক্ট করে। সার্ভার 404 বা 500 স্ট্যাটাস পাঠালেও fetch প্রমিজ রিজলভ হয়! তাই সর্বদা `if (!response.ok)` চেক করতে হয়।
