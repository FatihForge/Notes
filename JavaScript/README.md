# ⚡ JavaScript Foundation & Core Language Architecture

জাভাস্ক্রিপ্ট হলো আধুনিক ওয়েব ডেভেলপমেন্ট এবং সম্পূর্ণ **MERN Stack (MongoDB, Express.js, React, Node.js)**-এর মূল ভিত্তি। ক্লায়েন্ট-সাইডে React ইউজার ইন্টারফেস থেকে শুরু করে সার্ভার-সাইডে Node.js ও Express.js ব্যাকএন্ড—সবকিছুই জাভাস্ক্রিপ্টের উপর প্রতিষ্ঠিত।

এই ডিরেক্টরিতে জাভাস্ক্রিপ্টের মৌলিক সিনট্যাক্স থেকে শুরু করে ডোম ম্যানিপুলেশন, অবজেক্ট-ওরিয়েন্টেড ক্লাস, অ্যাসিনক্রোনাস প্রোগ্রামিং এবং ক্লোজার আর্কিটেকচার নিয়ে ১২টি পূর্ণাঙ্গ ও সমৃদ্ধ স্টাডি নোট অন্তর্ভুক্ত রয়েছে।
