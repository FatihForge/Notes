## ১. অ্যারে কী? (What is it?)

ওয়েব ডেভেলপমেন্টের প্র্যাক্টিক্যাল প্রেক্ষাপটে ডেটা বা তথ্য গুছিয়ে রাখার জন্য **Arrays** একটি অত্যন্ত শক্তিশালী **লিনিয়ার ডেটা স্ট্রাকচার (Linear Data Structure)**।

সহজ ভাষায়, **Array হলো অনেকগুলো আইটেমের একটি সুসংগঠিত সংগ্রহ বা Collection of items**। একই ধরনের অনেকগুলো ডেটা নিয়ে কাজ করার সময় সেগুলোকে একটি সিঙ্গেল ভেরিয়েবলের অধীনে বা *"Single Umbrella"*-র নিচে রাখার কার্যকর পদ্ধতিই হলো অ্যারে।

### 🎯 Strategic Insight

JavaScript-এ কারিগরিভাবে অ্যারে হলো এক ধরনের **বিশেষ অবজেক্ট (Special Object)**। সাধারণ অবজেক্টে যেখানে আমরা কাস্টম Key-Value পেয়ার ব্যবহার করি, অ্যারেতে সেখানে ডেটাগুলো একটি নির্দিষ্ট পজিশন বা **Index (0, 1, 2...)** অনুযায়ী ক্রমান্বয়ে সাজানো থাকে।

## ২. কেন এটি গুরুত্বপূর্ণ? (Why is it important?)

ধরুন একটি ক্লাসের ৫০ জন বা ৫০০ জন শিক্ষার্থীর পরীক্ষার নম্বর সেভ করতে হবে। ৫০টি আলাদা ভেরিয়েবল (`mark1`, `mark2`, ..., `mark50`) তৈরি করা সম্ভব হলেও তা চরম অবৈজ্ঞানিক ও বিশৃঙ্খল। একজন দক্ষ ডেভেলপার হিসেবে অ্যারে ব্যবহারের মূল কারণগুলো হলো:

              Single Variable Name

হাজারো সম্পর্কিত তথ্য একটিমাত্র ভেরিয়েবল নামের অধীনে পরিচালনা করা যায়।

              Reduced Complexity

অসংখ্য নাম ট্র্যাক করার বদলে ইনডেক্স ধরে যেকোনো উপাদান চোখের পলকে খুঁজে পাওয়া যায়।

              Sequential Access

অ্যারেতে ডেটার ক্রম বা সিকোয়েন্স বজায় থাকে, যা লুপ চালিয়ে প্রসেস করার জন্য অপরিহার্য।

## ৩. মূল ধারণাসমূহ (Core Concepts)

### 3.1
              Creating & Accessing Arrays

জাভাস্ক্রিপ্টে অ্যারে তৈরি করার জন্য আমরা স্কয়ার ব্র্যাকেট `[ ]` ব্যবহার করি এবং উপাদানগুলোকে কমা দিয়ে আলাদা করি।

                array-basics.js
                Copy

```javascript
let marks = [97, 82, 75, 64, 36];

// প্রথম আইটেম অ্যাক্সেস (০-ইনডেক্স):
console.log(marks[0]); // 97

// মোট উপাদানের সংখ্যা:
console.log(marks.length); // 5

// অস্তিত্বহীন ইনডেক্স অ্যাক্সেস:
console.log(marks[100]); // undefined
```

### 3.2
              Array Mutability (ইন্টারভিউ হট টপিক!)

              💡 **Interview Pro-Tip:** JavaScript-এ **Strings হলো Immutable** (ইন-প্লেস কোনো ক্যারেক্টার পরিবর্তন করা যায় না), কিন্তু **Arrays হলো Mutable**। অর্থাৎ, অ্যারের ভিতরের ভ্যালু সরাসরি মেমোরিতে পরিবর্তন করা সম্ভব।

                mutability.js
                Copy

```javascript
let marks = [97, 82, 75];

// ইন-প্লেস মান পরিবর্তন:
marks[0] = 66;

console.log(marks); // [66, 82, 75] — অরিজিনাল মেমোরি পরিবর্তন হয়েছে!
```

## ৪. গুরুত্বপূর্ণ অ্যারে মেথড ও প্রপার্টি

| Method / Property | কাজ / Purpose | Return Value | Important Note |
| --- | --- | --- | --- |
| length | অ্যারের মোট দৈর্ঘ্য বা উপাদান সংখ্যা জানায়। | Number | এটি একটি Property, মেথড নয় (ব্র্যাকেট ছাড়া লিখতে হয়)। |
| push() | অ্যারের শেষ প্রান্তে নতুন আইটেম যোগ করে। | New length | অরিজিনাল অ্যারে সরাসরি পরিবর্তন (Mutate) করে। |
| pop() | অ্যারের শেষ আইটেমটি মুছে ফেলে। | Deleted item | অরিজিনাল অ্যারে সরাসরি পরিবর্তন (Mutate) করে। |
| unshift() | অ্যারের শুরুতে নতুন আইটেম যোগ করে। | New length | শুরুতে ভ্যালু ইনসার্ট করে সব ইনডেক্স শিফট করায়। |
| shift() | অ্যারের প্রথম উপাদানটি মুছে ফেলে। | Deleted item | শুরুর ভ্যালু ডিলিট করে। |
| concat() | একাধিক অ্যারেকে একসাথে জোড়া দেয়। | New Array | একটি নতুন অ্যারে রিটার্ন করে, মূল অ্যারে অক্ষত থাকে। |
| slice(start, end) | নির্দিষ্ট অংশের সাব-অ্যারে কেটে আনে। | New Array | end ইনডেক্স অন্তর্ভুক্ত হয় না। মূল অ্যারে অক্ষত থাকে। |
| splice() | যেকোনো পজিশনে আইটেম যোগ, ডিলিট বা রিপ্লেস। | Deleted items | সরাসরি মূল অ্যারে মডিফাই করে। সিনট্যাক্স: splice(start, delCount, newEl)। |

## ৫. গুরুত্বপূর্ণ তুলনা (Comparisons)

### Array বনাম Object

| ফিচার | Array (অ্যারে) | Object (অবজেক্ট) |
| --- | --- | --- |
| ডেটা অ্যাক্সেস | ইনডেক্স ভিত্তিক (0, 1, 2...) | কাস্টম কী ভিত্তিক (Key-Value) |
| কালেকশন ধরন | সিকোয়েনশিয়াল বা লিনিয়ার কালেকশন | সম্পর্কিত বৈশিষ্ট্যের অ্যাসোসিয়েটিভ কালেকশন |

### Array বনাম String (Mutability)

| ফিচার | Array | String |
| --- | --- | --- |
| Mutability | Mutable (পরিবর্তনশীল) | Immutable (অপরিবর্তনশীল) |
| ইন-প্লেস পরিবর্তন | arr[0] = 'X'; // সফলভাবে কাজ করবে | str[0] = 'X'; // ব্যর্থ হবে (কোনো পরিবর্তন হবে না) |

## ৬. সাধারণ ভুলসমূহ (Common Mistakes)

১. typeof [] চেক করে "array" প্রত্যাশা করা

                  typeof [1, 2, 3]; // ❌ রিটার্ন করে "object"!

                  Array.isArray([1, 2, 3]); // ✅ রিটার্ন করে true

কোনো ভেরিয়েবল সত্যিই অ্যারে কিনা তা যাচাই করতে সর্বদা `Array.isArray()` ব্যবহার করুন।

২. length-কে ফাংশনের মতো কল করা

                  let count = arr.length(); // ❌ TypeError: arr.length is not a function

                  let count = arr.length; // ✅ সঠিক (Property)

## ৭. দ্রুত ঝালাই (Quick Revision)

* ✓
                অ্যারে টাইপ: এটি একটি বিশেষ ধরণের অবজেক্ট যার ইনডেক্স ০ থেকে length - 1 পর্যন্ত বিস্তৃত।

* ✓
                মিউটেবিলিটি: অ্যারে সরাসরি পরিবর্তনযোগ্য (Mutable)।

* ✓
                মেথডস সামারি: push/pop শেষে কাজ করে, unshift/shift শুরুতে কাজ করে, আর splice যেকোনো পজিশনে কাজ করে।
