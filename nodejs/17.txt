## Introduction

র-মঙ্গোডিবি (Raw MongoDB) দিয়ে ব্যাকএন্ড কোড লিখতে লিখতে কি আপনি ক্লান্ত? স্কিমাহীন ডাটাবেসে ভুল ডাটা জমতে জমতে অ্যাপ্লিকেশন কি বিশৃঙ্খল হয়ে পড়ছে?

ডাটাবেসের সম্পূর্ণ স্বাধীনতাই কখনো কখনো কাল হয়ে দাঁড়ায়! কিন্তু কেমন হতো যদি মঙ্গোডিবি-র নমনীয়তার সাথে এসকিউএল (SQL)-এর মতো একটি সুন্দর স্ট্রাকচার এবং ভ্যালিডেশন যুক্ত করা যেত? ঠিক এই কাজটাই করে **Mongoose**।

এই পাঠটি শেষ করার পর, আপনি সক্ষম হবেন:

* Mongoose-এর মূল ধারণা এবং **ODM (Object Data Modeling)**\-এর প্রয়োজনীয়তা ব্যাখ্যা করতে।
* Node.js অ্যাপ্লিকেশনে Mongoose ইন্সটল ও কনফিগার করতে।
* **Schema** এবং **Model** তৈরি করে ডাটা টাইপ ও ভ্যালিডেশন নিশ্চিত করতে।
* Mongoose-এর বিল্ট-ইন মেথড ব্যবহার করে সহজে **CRUD (Create, Read, Update, Delete)** অপারেশন পরিচালনা করতে।
* **Pre Hooks** এবং **populate()** মেথড ব্যবহার করে ডাটা রিলেশনশিপ বজায় রাখতে।

## মঙ্গুস (Mongoose) কী এবং কেন এটি প্রয়োজন?

যখন আমরা র-মঙ্গোডিবি ড্রাইভার (Raw MongoDB Driver) ব্যবহার করে ব্যাকএন্ডের কোড লিখি, তখন ছোট প্রজেক্টে কাজ চালানো সহজ হলেও প্রজেক্ট বড় হওয়ার সাথে সাথে ডাটাবেস হ্যান্ডেল করা বেশ কঠিন হয়ে পড়ে। আমাদের প্রতিটা কোয়েরি ম্যানুয়ালি লিখতে হয়—যেমন কালেকশন সিলেক্ট করা, `find()`, `toArray()`, বা `deleteOne()` কল করা।

### মঙ্গোডিবি-র স্বাধীনতা বনাম স্ট্রাকচার

মঙ্গোডিবি আমাদের একধরনের চরম স্বাধীনতা দেয়। এটি জাভাস্ক্রিপ্টের মতো 'Schemaless'—অর্থাৎ আপনি যেকোনো ডকুমেন্টে যেকোনো প্রপার্টি সংরক্ষণ করতে পারেন।

একটি বাস্তব জীবনের উদাহরণ দেওয়া যাক: ছোট বাচ্চাদের যদি অভিভাবকরা সম্পূর্ণ স্বাধীন ছেড়ে দেন যে—"যখন ইচ্ছা পড়ো, যখন ইচ্ছা গেম খেলো", তখন কিছু গুটিবাড়ে বাচ্চা হয়তো নিজেকে সামলে নেয়, কিন্তু অধিকাংশেরই পড়াশোনা বিশৃঙ্খল হয়ে পড়ে! ডাটাবেসের ক্ষেত্রেও ঠিক তা-ই হয়। ডেভেলপার কোডে কোনো ভুল করলে ডাটাবেসে ভুল বা অসম্পূর্ণ ডাটা জমতে থাকে। তাই ডাটাবেসে কিছুটা **স্ট্রাকচার বা শৃঙ্খলা** থাকা জরুরি।

### মধ্যস্থতাকারী এজেন্ট হিসেবে Mongoose

মনে করুন, একজন বয়স্ক মানুষ ট্রেনের টিকিট কাটবেন। নিজে অনলাইনে জটিল টিকিট পোর্টালে না গিয়ে তিনি সাইবার ক্যাফে বা ট্রাভেল এজেন্সিতে যান। তিনি এজেন্টকে শুধু বুঝিয়ে বলেন, আর এজেন্ট ইন্টারনালি রেলওয়ের পোর্টালে টিকিটটি বুক করে দেয়।

**Mongoose** হলো আমাদের Node.js অ্যাপ্লিকেশন এবং MongoDB-এর মাঝের সেই বিশ্বস্ত এজেন্ট বা **মিডল লেয়ার (Middle Layer)**। এখন থেকে আমাদের ব্যাকএন্ড সরাসরি র-মঙ্গোডিবির সাথে কথা বলবে না, বরঞ্চ Mongoose-এর সাথে কথা বলবে। আর Mongoose ব্যাকগ্রাউন্ডে মঙ্গোডিবিকে নিখুঁতভাবে ম্যানেজ করবে।

### ODM (Object Data Modeling) কী?

রিলেশনাল ডাটাবেসে (যেমন SQL) ডাটা ও অবজেক্টের ম্যাপিংকে বলা হয় **ORM (Object Relational Modeling)**। কিন্তু মঙ্গোডিবি রিলেশনাল ডাটাবেস না হওয়ায় Mongoose-কে বলা হয় **ODM (Object Data Modeling)**। এটি Node.js এবং MongoDB-এর জন্য একটি Schema-based লাইব্রেরি, যা নিচের সুবিধাগুলো দেয়:

1. **Schema Definition:** ডাটার নির্দিষ্ট টাইপ (String, Number, Object) ঠিক করে দেয়।
2. **Validation &amp; Type Casting:** ভুল ডাটা টাইপ আসলে আটকে দেয় বা স্বয়ংক্রিয়ভাবে সঠিক টাইপে কনভার্ট করার চেষ্টা করে।
3. **Pre &amp; Post Hooks:** ডাটা সেভ বা ডিলিট করার আগে ও পরে নির্দিষ্ট জাভাস্ক্রিপ্ট কোড চালানোর সুবিধা দেয়।
4. **Easy Relationships:** একাধিক কালেকশনের মধ্যে সহজে সম্পর্ক স্থাপন করে।

## প্রজেক্টে Mongoose সেটআপ ও ডাটাবেস কানেকশন

এখন চলুন আমাদের Node.js প্রজেক্টে Mongoose সেটআপ করি। পুরানো ডাটাবেস ইউটিলিটি কোড বাদ দিয়ে কীভাবে Mongoose কানেক্ট করতে হয় তা ধাপে ধাপে দেখে নেওয়া যাক।

### ধাপ ১: Mongoose প্যাকেজ ইন্সটল করা

টার্মিনালে নিচের এনপিএম (NPM) কমান্ডটি চালিয়ে Mongoose ইন্সটল করুন:

```
npm install mongoose

```

ইন্সটল শেষে `package.json` ফাইলের `dependencies`\-এ Mongoose যুক্ত হয়েছে কিনা তা দেখে নিন।

### ধাপ ২: ডাটাবেস কানেকশন কনফিগার করা (`app.js`)

পূর্বে আমরা একটি আলাদা `databaseUtil.js` ফাইল বানিয়ে ডাটাবেস ক্লায়েন্ট কানেক্ট করতাম। Mongoose ব্যবহার করলে ডাটাবেস কানেক্ট করা অনেক সহজ হয়ে যায়।

এখন আমরা সরাসরি `app.js` ফাইলে `mongoose.connect()` ব্যবহার করতে পারি:

```
const mongoose = require('mongoose');

// ডাটাবেস পাথ ইউআরআই (শেষে ডাটাবেসের নাম /airbnb যুক্ত করা হয়েছে)
const DB_PATH = "mongodb+srv://root:password@cluster0.mongodb.net/airbnb";

mongoose.connect(DB_PATH)
  .then(() =&gt; {
    console.log('Connected to MongoDB via Mongoose!');
    app.listen(3000, () =&gt; {
      console.log('Server is running on port 3000');
    });
  })
  .catch(err =&gt; {
    console.log('Error while connecting to MongoDB:', err);
  });

```

&gt; **গুরুত্বপূর্ণ নোট:** কানেকশন স্ট্রিং বা ইউআরআই (URI)-এর শেষে ডাটাবেসের নাম (যেমন `/airbnb`) দিয়ে দিলে Mongoose সরাসরি সেই ডাটাবেসের সাথেই কানেক্ট হয়ে যাবে। ফলে পুরানো `databaseUtil.js` ফাইলটির আর কোনো প্রয়োজনই থাকে না এবং সেটিকে প্রজেক্ট থেকে সম্পূর্ণ মুছে ফেলা যায়!

## স্কিমা (Schema) এবং মডেল (Model) তৈরি করা

Mongoose-এর আসল শক্তি হলো এর **Schema** এবং **Model**। কাস্টম ক্লাসের মাধ্যমে দীর্ঘ কোড না লিখে আমরা শুধু স্কিমা ডিফাইন করব, আর বাকি সব কাজ Mongoose নিজের কাঁধে তুলে নেবে।

### স্কিমা (Schema) কী?

স্কিমা হলো ডাটাবেসে গচ্ছিত ডকুমেন্টের একটি নীলক নকশা (Blueprint)। একটি ডকুমেন্টে কী কী ফিল্ড থাকবে, তাদের ডাটা টাইপ কী হবে এবং ফিল্ডগুলো বাধ্যতামূলক (Required) কিনা—তা স্কিমা নির্ধারণ করে।

আসুন আমাদের Airbnb প্রজেক্টের জন্য একটি `Home` স্কিমা তৈরি করি (`models/home.js`):

```
const mongoose = require('mongoose');

// ১. স্কিমা ডিফাইন করা
const homeSchema = new mongoose.Schema({
  houseName: { type: String, required: true },
  price: { type: Number, required: true },
  location: { type: String, required: true },
  rating: { type: Number, required: true },
  photoUrl: String,      // যদি শুধু টাইপ ডিফাইন করতে হয়, তবে সরাসরি String লেখা যায়
  description: String
});

```

এখানে `_id` ফিল্ড আলাদাভাবে লেখার প্রয়োজন নেই, কারণ Mongoose স্বয়ংক্রিয়ভাবে প্রতিটি ডকুমেন্টের জন্য একটি ইউনিক `_id` জেনারেট করে।

### মডেল (Model) কী?

স্কিমা হলো কেবল নকশা, কিন্তু ডাটাবেসে ক্রুড (CRUD) অপারেশন চালানোর জন্য সেই নকশাকে মডেলে রূপান্তর করতে হয়। মডেল তৈরি করতে `mongoose.model()` ব্যবহার করা হয়:

```
// ২. স্কিমা থেকে মডেল তৈরি ও এক্সপোর্ট করা
module.exports = mongoose.model('Home', homeSchema);

```

&gt; **Mongoose ম্যাজিক:** যখন আপনি মডেলের নাম দিবেন `'Home'`, Mongoose চালাকি করে ডাটাবেসে এই কালেকশনের নাম ছোট হাতের ও বহুবচন (Plural) বানিয়ে **homes** নামে সেভ করবে!

### 💡 Mongoose টার্মিনোলজি ফ্ল্যাশকার্ড
> [!IMPORTANT]
> **কুইক রিভিশন পয়েন্টস (Quick Revision Points):**
> Schema, Model, Required, Type Casting এবং Object ID-এর মতো গুরুত্বপূর্ণ Mongoose শব্দাবলীর ওপর ফ্ল্যাশকার্ড।

## Mongoose দিয়ে CRUD অপারেশন সম্পন্ন করা

Mongoose মডেল তৈরি হয়ে গেলে ডাটা তৈরি করা, পড়া, আপডেট করা এবং মুছে ফেলা (CRUD Operations) এক্কেবারে পানির মতো সহজ হয়ে যায়।

### ১. ডাটা তৈরি ও সেভ করা (Create)

নতুন ডাটা সেভ করার জন্য শুধু মডেলের একটি অবজেক্ট তৈরি করে `.save()` ডাকার প্রয়োজন হয়:

```
const Home = require('../models/home');

exports.postAddHome = (req, res, next) =&gt; {
  const home = new Home({
    houseName: req.body.houseName,
    price: req.body.price,
    location: req.body.location,
    rating: req.body.rating,
    photoUrl: req.body.photoUrl,
    description: req.body.description
  });

  home.save()
    .then(() =&gt; {
      console.log('Home saved successfully!');
      res.redirect('/host/host-homes');
    })
    .catch(err =&gt; console.log('Error saving home:', err));
};

```

### ২. ডাটা খোঁজা (Read)

* **সব ডাটা একসাথে খুঁজতে:** `Home.find()` ব্যবহার করা হয় (পুরানো `fetchAll()` বা `toToArray()` এর দরকার নেই)।

```
Home.find().then(homes =&gt; {
  res.render('store/home-list', { homes: homes });
});

```

* **নির্দিষ্ট ID দিয়ে একটি ডাটা খুঁজতে:** `Home.findById(id)` ব্যবহার করা হয়।

```
Home.findById(homeId).then(home =&gt; {
  res.render('store/home-detail', { home: home });
});

```

### ৩. ডাটা আপডেট করা (Update)

প্রথমে ডাটা খুঁজে বের করে তার প্রপার্টি পরিবর্তন করে আবার `.save()` করা যায়:

```
Home.findById(homeId).then(home =&gt; {
  home.houseName = req.body.houseName;
  home.price = req.body.price;
  return home.save(); // পরিবর্তিত ডাটা সেভ হবে
}).then(() =&gt; {
  res.redirect('/host/host-homes');
});

```

### ৪. ডাটা ডিলিট করা (Delete)

Mongoose-এর ইন-বিল্ট `findByIdAndDelete()` মেথড ব্যবহার করে সরাসরি ডাটা ডিলিট করা সম্ভব:

```
Home.findByIdAndDelete(homeId)
  .then(() =&gt; {
    res.redirect('/host/host-homes');
  });

```

### 📌 Mongoose CRUD অপারেশন টিউটোরিয়াল
> Mongoose-এর save(), find(), findById() এবং findByIdAndDelete() ব্যবহারের ব্যবহারিক ওভারভিউ।

## মিডলওয়্যার/হুকস (Hooks) এবং ডাটা রিলেশনশিপ (Relationships &amp; Population)

Mongoose আমাদের আরও দুটি অত্যন্ত আধুনিক ও শক্তিশালী ফিচার প্রদান করে: **Hooks (Middleware)** এবং **Population**।

### ১. Pre &amp; Post Hooks (মিডলওয়্যার)

কোনো ডকুমেন্ট সেভ বা ডিলিট হওয়ার ঠিক আগে বা পরে আপনি যদি স্বয়ংক্রিয়ভাবে কোনো কোড এক্সিকিউট করতে চান, তবে Hooks ব্যবহার করতে পারেন।

**ক্যাসকেড ডিলিট (Cascade Delete)-এর উদাহরণ:** যদি একজন হোস্ট একটি বাসা (`Home`) ডিলিট করে দেয়, তবে ব্যবহারকারীদের প্রিয় তালিকা (`Favorite`) থেকেও সেই বাসার আইডিটি স্বয়ংক্রিয়ভাবে মুছে যাওয়া উচিত। এটি করার জন্য `homeSchema`\-তে একটি `pre` হুক সেট করা যায়:

```
const Favorite = require('./favorite');

// findOneAndDelete কল হওয়ার ঠিক পূর্বে এই হুকটি চলবে
homeSchema.pre('findOneAndDelete', async function(next) {
  const homeId = this.getQuery()['_id']; // ডিলিট হতে যাওয়া Home-এর ID
  await Favorite.deleteMany({ houseId: homeId }); // উক্ত বাসার সব ফেভারিট ডিলিট
  next();
});

```

### ২. রিলেশনশিপ ও `populate()`

একটি কালেকশনের সাথে অন্য কালেকশনের সম্পর্ক কীভাবে তৈরি করবেন? যেমন—ফেভারিট কালেকশনে হোম-এর রেফারেন্স রাখা:

```
const favoriteSchema = new mongoose.Schema({
  houseId: {
    type: mongoose.Schema.Types.ObjectId,
    ref: 'Home', // Home মডেলের সাথে কানেক্ট করা হলো
    required: true,
    unique: true
  }
});

```

এখন, যখন আপনি ফেভারিট ডাটা তুলবেন, তখন শুধু আইডি না এনে সম্পূর্ণ বাসার তথ্য একবারে আনার জন্য Mongoose-এর **populate()** মেথড ব্যবহার করা হয়:

```
Favorite.find()
  .populate('houseId') // houseId ফিল্ডটি সম্পূর্ণ Home অবজেক্ট দিয়ে পূরণ হয়ে যাবে
  .then(favorites =&gt; {
    // এখন favorites[0].houseId-এর ভেতরেই পুরো Home অবজেক্ট রয়েছে!
    console.log(favorites);
  });

```

এর ফলে আমাদের ম্যানুয়ালি লুপ বা ফিল্টার চালিয়ে দুই কালেকশন মেলাতে হয় না। ডাটাবেস লেভেলেই কাজটা অত্যন্ত দ্রুত ও দক্ষতার সাথে সম্পন্ন হয়।

## Summary

Mongoose হলো Node.js এবং MongoDB-এর মধ্যে একটি আদর্শ মাধ্যম (ODM), যা নো-এসকিউএল (NoSQL) ডাটাবেসে স্কিমা এবং শৃঙ্খলার চমৎকার সমন্বয় ঘটায়। Mongoose ব্যবহার করার ফলে ব্যাকএন্ড কোডের পরিমাণ প্রায় ৮০% কমে যায় এবং প্রজেক্টের ডাটা স্ট্রাকচার অনেক বেশি নিরাপদ ও বজায় রাখা সহজ হয়।

### Key Takeaways

* **ODM সুবিধা:** Mongoose একটি মিডল লেয়ার বা অবজেক্ট ডাটা মডেলিং লাইব্রেরি যা র-মঙ্গোডিবি কোয়েরির জটিলতা দূর করে।
* **Schema &amp; Model:** `mongoose.Schema` দিয়ে ডাটার টাইপ ও রিকোয়ারমেন্ট নির্ধারণ করা হয় এবং `mongoose.model()` দিয়ে ক্রুড মেথড সমৃদ্ধ মডেল তৈরি করা হয়।
* **সরলীকৃত CRUD:** `save()`, `find()`, `findById()`, এবং `findByIdAndDelete()`\-এর মতো তৈরি মেথডের মাধ্যমে সহজেই ডাটা পরিচালনা করা যায়।
* **Pre Hooks:** ডাটা মুছে ফেলার সময় আনুষঙ্গিক ডাটা (যেমন ফেভারিট) স্বয়ংক্রিয়ভাবে মুছে ফেলার জন্য `pre` হুক ব্যবহার করা যায়।
* **Population:** `ref` এবং `populate()` মেথড ব্যবহার করে একাধিক কালেকশনের মাঝে সহজে সম্পর্ক তৈরি এবং পূর্ণাঙ্গ তথ্য ফেচ করা যায়।
