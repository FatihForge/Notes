# 🍃 MongoDB & Mongoose Database Engineering

MongoDB হলো বিশ্বের শীর্ষস্থানীয় ডকুমেন্ট-বেসড NoSQL ডেটাবেস। এটি JSON-সদৃশ নমনীয় BSON ফরম্যাটে ডেটা সংরক্ষণ করে, যা আধুনিক স্কেলযোগ্য ওয়েব অ্যাপ্লিকেশনের জন্য অত্যন্ত উপযুক্ত। MERN স্ট্যাকের নোড/এক্সপ্রেস অ্যাপ্লিকেশনে ডেটা মডেলিং এবং ভ্যালিডেশনের জন্য Mongoose ODM ব্যবহার করা হয়।
