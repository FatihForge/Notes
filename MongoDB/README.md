# 🍃 MongoDB & Mongoose Study Notes

MongoDB হলো একটি ডকুমেন্ট-ওরিয়েন্টেড, ওপেন-সোর্স NoSQL ডেটাবেস। আধুনিক ওয়েব অ্যাপ্লিকেশনে ফ্লেক্সিবল ও ডাইনামিক ডেটা সংরক্ষণ ও কুয়েরি করার জন্য এটি বহুল ব্যবহৃত। MERN স্ট্যাকে Node.js-এর সাথে ডেটাবেস কানেক্টিভিটির জন্য Mongoose ODM ব্যবহার করা হয়।
