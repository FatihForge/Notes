# 🔷 TypeScript Engineering Study Notes

TypeScript হলো Microsoft দ্বারা তৈরি একটি শক্তিশালী, ওপেন-সোর্স এবং স্ট্যাটিকালি টাইপড প্রোগ্রামিং ভাষা, যা JavaScript-এর সুপারসেট হিসেবে কাজ করে। এটি আধুনিক ওয়েব অ্যাপ্লিকেশন, Node.js ব্যাকএন্ড এবং React ফ্রন্টএন্ডে কোড লেখার সময় কম্পাইল-টাইম টাইপ চেকিং এবং উন্নত IntelliSense প্রদান করে বাগ-মুক্ত ও নির্ভরযোগ্য সফটওয়্যার তৈরি করতে সাহায্য করে।
