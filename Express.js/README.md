# 🚀 Express.js Web Framework Study Notes

Express.js হলো Node.js-এর জন্য অত্যন্ত জনপ্রিয়, ফ্লেক্সিবল ও মিনিমালিস্ট একটি ওয়েব অ্যাপ্লিকেশন ফ্রেমওয়ার্ক। এটি সহজে ও দ্রুতগতিতে স্কেলেবল RESTful API এবং ব্যাকএন্ড সার্ভিস তৈরি করতে ব্যবহৃত হয়।
